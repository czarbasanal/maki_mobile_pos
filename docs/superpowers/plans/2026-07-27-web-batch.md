> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the approved 11-item web-admin batch (spec: `docs/superpowers/specs/2026-07-27-web-batch-design.md`) — UI fixes, pagination, day-sales view, deletes, full Expenses build, Drafts→Job Orders, and activity-logging wiring.

## Global Constraints

- Branch `feat/web-batch-11` off main; one commit per task; TDD every task (RED evidence); `cd web_admin && npm run typecheck && npm run test` green per task.
- Copy/labels follow existing pages' tone; identifiers (sale numbers, JO numbers, SKUs) render `font-mono`.
- Pager standard: 25/page, client-side slice, "«x–y of N»" + Prev/Next, hidden when N ≤ 25.
- Never `git add -A` (scripts/create-user.mjs, scripts/rename-product-category.mjs stay untracked). No deploys (hosting deploy is user-gated at the end).
- Mobile app untouched; +18 hold unaffected.
